## 一、老人端（大字版，全程可语音朗读）

### 1. 登录/注册
- 打开 H5 地址 → 输入手机号和密码 → 点「登 录」。
- 首次使用点「注册」，填写姓名、手机号、密码，选择身份（老年人），**阅读并勾选知情同意书**后注册。
- 演示账号可点「自动填入」。

### 2. 首页
- 顶部大字显示**今日服药进度**（已服/总数）。
- 若有**高危用药冲突**，首页顶部会出现红色横幅，点击查看大白话解释和依据来源。
- 六个大按钮功能卡：拍照识药 / 今日用药 / 问药助手 / 用药计划 / 家庭协同 / 我的。
- 字体可在「我的」里切换三档（标准/大/特大），所有内容支持**点击喇叭语音朗读**。

### 3. 拍照识药（3步完成）
1. 点「拍照识药」→ 拍摄药盒正面（有药名的一面），光线要亮；也可从相册选。
2. 系统识别文字后给出**Top-3 候选药名**（带置信度），点选你拍的那个药；认不出来可「手动输入药名」。
3. 选择每天服药时间（可多选）→「确认加入用药计划」。若与在用药有冲突，会**弹窗警示**并给出依据。
- 隐私承诺：照片仅本次识别使用，**识别完成立即删除，平台不保存原图**。

### 4. 今日用药（打卡）
- 大按钮列出今天每个时点的服药任务。到点后应用内会出现提醒（服药前10分钟）。
- 吃完药点绿色大按钮「已服药」→ 记录成功。
- 判定规则（可解释）：计划时间**±10分钟内=TAKEN 按时**；超过10分钟补打=LATE 迟打卡；超过60分钟未打卡系统自动记 MISSED 漏服——**漏服后仍可补打卡**，状态转为 LATE。
- 「近7天依从率」实时可见，记录页支持按天分组回看并整日朗读。

### 5. 问药助手（有依据才回答）
- 直接问：「阿司匹林肠溶片怎么吃」「二甲双胍有什么副作用」「华法林和阿司匹林能一起吃吗」。
- 每条回答**逐条标注来源**（药品说明书/权威指南/科普），可点喇叭朗读。
- 回答下方的「📚 知识库引用」面板可展开：每条引用显示**来源编号、药品名、所属章节（用法用量/禁忌等）、相关度分数、原文摘录**，回答中的 [来源N] 角标与之一一对应；元信息行还会显示生成模式（LLM受控生成/知识库摘编）、置信度、知识库片段规模（当前 1022 片段）与检索耗时——这就是 RAG（检索增强生成）的完整证据链：**先检索、后生成、可溯源、无据即拒答**。
- 三种情况会如实拒答：①知识库没有依据；②问题超出用药范围（如股票、诊断）；③问了知识库未收录的药。**本平台不提供诊断和处方，请务必遵医嘱。**

### 6. 用药计划
- 「用药计划」页可新增（搜索药名→选时间）或停用计划；停用后今日任务即消失。
- 新建计划时系统自动做**四类冲突校验**：成分重复 / 同类叠加 / 禁忌配伍 / 老年慎用（依据 Beers 标准与中国老年人潜在不适当用药判断标准），HIGH>MEDIUM>LOW 分级展示，每条都有大白话解释与文献依据。

### 7. 家庭协同（授权矩阵，你说了算）
- 在「家庭协同」页输入子女手机号并**勾选授权范围**：看用药摘要 / 看依从率 / 收漏服与冲突提醒——可以只给一部分。
- 子女发起绑定后，你需要在这里点「同意」才生效；**随时可撤销，撤销即时生效**。
- 家属只能看到脱敏汇总（如"张*芳"、"阿司**"），看不到完整明细。

### 8. 我的
- 字体三档切换、语音朗读开关、**震动提醒开关**（高危冲突长三段震、到点未服双段震、打卡成功轻一下；iPhone Safari 不支持网页震动，自动以弹窗+语音代替）、健康信息同意开关（可撤回）。
- 隐私说明：用药记录保存至注销后30天；识别原图不落盘；审计日志保存6个月。
- 「注销账号」需两次确认，注销后数据按规定删除。

## 二、家属端

1. 用家属账号登录（注册时身份选「家属」）。统一入口页点「家属端」卡片可自动登录演示账号。
2. 「家庭协同」→ 输入老人注册手机号 → 勾选想申请的授权 → 发送绑定申请。
3. 等老人在 TA 的手机上点「同意」。
4. 首页即出现老人卡片：**今日已服 x/y、用药几种、近7天依从率、漏服次数与风险级别**（按授权范围展示，药名脱敏）。
5. **实时风险警报**（RECEIVE_ALERTS 授权后）：老人一新增高危用药计划，家属页面**秒级弹出红色警报**（SSE 推送，无需刷新），同时手机**强震动 + 语音播报**"请尽快联系老人"；警报落库可在首页"风险提醒"区补看、标记已读。同一风险对同一家属只推一次（服务端去重）。
6. **帮爸妈管计划**（MANAGE_PLANS 授权后）：首页老人卡片点「帮TA管理」→ 进入代办视图，可替老人新增/停用用药计划；新增时同样触发冲突校验，高危结果会立刻推警报给你。
7. 家属也可使用问药助手帮老人查询。

## 三、管理端（管理员）

浏览器打开 `http://127.0.0.1:8080/admin/`，用 `admin / 123456` 登录。

| 菜单 | 功能 |
|---|---|
| **数据仪表盘** | 用户/药品/规则/打卡统计卡；近7天识别与问答调用趋势（含平均延迟）；依从率与**问答引用覆盖率**仪表盘；角色分布 |
| **用户与权限** | 搜索用户（手机号脱敏展示）、变更角色（三级权限 ELDER/FAMILY/ADMIN，变更留审计） |
| **药品知识库** | 检索/新增/编辑药品全字段（通用名、成分、用法、禁忌…）；编辑后**版本自动+1**并即时同步 AI 词典与 RAG 知识库；可启停条目 |
| **冲突规则库** | 按类型/审核状态筛选；新增规则默认**待审核**；药师审核流（填审核人→通过/驳回，通过即生效并热推送AI服务）；规则启停；手动全量同步 |
| **日志审计** | 识别日志（OCR文本/Top-3候选/用户确认/延迟）、问答日志（问题/回答/模式/引用/置信度/拒答标记）、操作审计（谁在何时做了什么，保存6个月） |

**药师审核工作流**（申报书合规要求）：新规则 → PENDING 待审核 → 审核人（执业药师）通过 → APPROVED 参与校验；驳回 → REJECTED 不生效。种子规则已标 APPROVED（依据权威标准整理），生产上线前应逐条复核。

## 四、常见问题

**Q: 识别不准/认不出我的药？**
知识库当前收录 144 种老年常用药（演示集）。未收录的药会识别失败，请手动输入药名，或由管理员在后台「药品知识库」新增（保存即生效）。拍摄时保证药名大字清晰、光线充足、正对镜头。

**Q: 问答为什么拒答？**
只有知识库里有依据时才回答，这是医疗产品的安全底线。拒答时请换"药名+问题"的问法；若药品未收录请让管理员添加。

**Q: 打卡时间判定能改吗？**
±10分钟按时/10-60分钟迟打/60分钟漏服为产品规则（可在 `PlanService` 中调整），设计目标是"可解释、不苛责老人"。

**Q: 家属看不到老人数据？**
检查三点：①绑定申请老人是否已同意；②授权范围是否包含对应项（摘要/依从/提醒分开授权）；③老人是否已撤销授权。

**Q: 手机上如何像 App 一样使用？**
手机浏览器打开 H5 地址 → 菜单「添加到主屏幕」。PWA 支持离线打开壳页面；拍照识药需联网。
