# 数据字典（MySQL 8.0 · 库名 medguard）

> 智慧养老安全用药辅助平台 · MedGuard v1.1
> 共 11 张表，全部 `mg_` 前缀、InnoDB、utf8mb4。建表脚本 `backend/src/main/resources/db/schema.sql`（幂等，启动自动执行）；索引补全由 `DbBootstrap.ensureIndex()` 启动时判存创建。

## 表清单

| # | 表名 | 用途 | 当前量级 |
|---|---|---|---|
| 1 | mg_user | 用户与三级角色 | 演示5人 |
| 2 | mg_family_bind | 家庭绑定与授权矩阵 | — |
| 3 | mg_medication | 药品知识库 | 144 条 |
| 4 | mg_conflict_rule | 四类冲突规则库 | 144 条 |
| 5 | mg_med_plan | 用药计划 | — |
| 6 | mg_checkin | 服药打卡 | 30天演示史 |
| 7 | mg_reminder | 应用内提醒 | — |
| 8 | mg_recognize_log | 拍照识药留痕（不存图） | — |
| 9 | mg_qa_log | RAG问答留痕 | — |

## 1. mg_user — 用户与三级角色

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | 自增 |
| phone | VARCHAR(20) | 手机号=登录账号，**唯一索引 uk_phone** |
| password | VARCHAR(120) | BCrypt 加盐哈希，绝不存明文 |
| name | VARCHAR(50) | 姓名 |
| role | VARCHAR(20) | ELDER老人 / FAMILY家属 / ADMIN管理员（idx_role） |
| birth_year | INT | 出生年份（适老化提示用） |
| consent_at | DATETIME | 知情同意时间（大字版知情同意书） |
| health_consent_at | DATETIME | 健康信息**单独同意**时间，可撤回 |
| deleted / deleted_at | TINYINT / DATETIME | 软删除标记；注销后 30 天级联物理清除 |
| created_at / updated_at | DATETIME | 自动维护 |

## 2. mg_family_bind — 家庭绑定与授权矩阵

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | |
| elder_id / family_id | BIGINT | 老人 / 家属用户 id，联合唯一 uk_pair |
| scopes | VARCHAR(200) | 授权范围 CSV：VIEW_SUMMARY / VIEW_ADHERENCE / RECEIVE_ALERTS / MANAGE_PLANS |
| status | VARCHAR(20) | PENDING / APPROVED / REJECTED / REVOKED |
| created_at / approved_at / revoked_at | DATETIME | 授权全生命周期；revoked 即时生效 |

索引：uk_pair(elder_id,family_id)、idx_family(family_id)、**idx_elder_status(elder_id,status)**〔v1.1 新增〕

## 3. mg_medication — 药品知识库（144 条）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | |
| generic_name | VARCHAR(100) | 通用名（idx_generic） |
| brand_name | VARCHAR(100) | 商品名（idx_brand） |
| ingredients | VARCHAR(500) | 成分 CSV（归一化后）——**冲突校验的基础** |
| drug_class | VARCHAR(100) | 药理分类，如 NSAIDs / 他汀类（CLASS_STACKING 依据） |
| indications / dosage / contraindications / precautions / adverse_reactions | TEXT | 说明书五段，RAG 知识源 |
| storage | VARCHAR(200) | 贮藏 |
| source | VARCHAR(300) | 知识来源（说明书/药典/权威科普），可追溯 |
| version / enabled | VARCHAR(20) / TINYINT | 版本与启用位 |

## 4. mg_conflict_rule — 四类冲突规则库（144 条）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | |
| rule_code | VARCHAR(60) | 规则编码，唯一 uk_code |
| rule_type | VARCHAR(30) | DUPLICATE_INGREDIENT 成分重复 / CLASS_STACKING 同类叠加 / CONTRAINDICATED 禁忌配伍 / ELDERLY_CAUTION 老年慎用（idx_type） |
| drug_a / drug_b | VARCHAR(100) | 药品/成分对（单药规则只有 A） |
| risk_level | VARCHAR(10) | HIGH / MEDIUM / LOW |
| explanation | VARCHAR(1000) | 给老人看的通俗解释（可朗读） |
| basis_source | VARCHAR(300) | 依据：说明书 / 中国老年人潜在不适当用药判断标准(2017) / AGS Beers(2023) |
| reviewed_by | VARCHAR(50) | 审核药师；新增规则标注"正式上线前待执业药师复核" |
| review_status / version / enabled | | PENDING/APPROVED、版本、启用位 |

## 5. mg_med_plan — 用药计划

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | |
| elder_id | BIGINT | 所属老人；**家属代办时经 MANAGE_PLANS 授权写入** |
| medication_id | BIGINT NULL | 关联知识库（手动建计划可为空） |
| med_name | VARCHAR(100) | 药品名**快照**（防知识库改名影响历史计划） |
| dose_text | VARCHAR(100) | 每次剂量，如"1片" |
| times | VARCHAR(200) | 每日服药时间点 CSV，如"08:00,20:00" |
| start_date / end_date | DATE | 起止；end_date 空=长期 |
| active | TINYINT | 1=进行中（停用时置0，保留历史） |

索引：idx_elder(elder_id, active)

## 6. mg_checkin — 服药打卡

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT PK | |
| plan_id / elder_id | BIGINT | 所属计划/老人 |
| med_name | VARCHAR(100) | 快照 |
| scheduled_at | DATETIME | 计划服药时间；uk_plan_time(plan_id,scheduled_at) 防重复生成 |
| checked_at | DATETIME NULL | 实际打卡时间 |
| status | VARCHAR(20) | PENDING / TAKEN / LATE迟到服用 / MISSED漏服（**可解释规则**：超时60分钟未打卡） |

索引：idx_elder_day(elder_id, scheduled_at)、**idx_plan_status(plan_id,status)**〔v1.1 新增，漏服扫描〕

## 7. mg_reminder — 应用内提醒

| 字段 | 说明 |
|---|---|
| elder_id / plan_id / due_at | 目标老人、来源计划、应提醒时间；uk_dedupe(elder_id,plan_id,due_at) 去重 |
| title / content | 提醒文案 |
| status | PENDING / READ / EXPIRED（idx_elder_status） |

## 8. mg_recognize_log — 拍照识药留痕

| 字段 | 说明 |
|---|---|
| user_id | 发起人（idx_user(user_id,created_at)） |
| ocr_text | OCR 文本——**隐私设计：无图片列，原图识别后即删** |
| candidates | Top-3 候选 JSON |
| chosen_medication_id / top_confidence / latency_ms | 用户确认项、置信度、耗时（用于识别准确率看板） |

## 9. mg_qa_log — RAG 问答留痕

| 字段 | 说明 |
|---|---|
| user_id / question / answer | 谁问了什么、系统答了什么 |
| sources | 来源片段 JSON——**引用覆盖率 100% 的证据** |
| confidence / refused / mode | 置信度、是否拒答、llm/extractive/extractive-fallback/guard |
| latency_ms | 耗时（idx_user(user_id,created_at)、**idx_refused_time(refused,created_at)**〔v1.1 新增，拒答率看板〕） |

## 10. mg_audit_log — 操作审计

| 字段 | 说明 |
|---|---|
| user_id / action / target_type / target_id | 谁对什么做了什么（**idx_user_time(user_id,created_at)**〔v1.1 新增〕） |
| detail / ip / created_at | 详情、来源 IP、时间（idx_time；保存 6 个月） |

## 11. mg_family_alert — 家属风险实时提醒

| 字段 | 说明 |
|---|---|
| elder_id / family_id | 触发老人、接收家属 |
| type / level / title / content | CONFLICT 等类型、HIGH/MEDIUM/LOW、文案 |
| dedup_key | 去重键；uk_dedup(dedup_key, family_id) **同一风险对同一家属只推一次** |
| read_flag / created_at | 已读位、时间（idx_family(family_id,id)、**idx_elder_level(elder_id,level)**〔v1.1 新增〕） |

## 索引总览（v1.1 补齐后）

| 表 | 索引 | 服务的查询 |
|---|---|---|
| mg_user | uk_phone | 登录 |
| mg_family_bind | uk_pair / idx_family / idx_elder_status | 绑定防重 / 家属查老人 / 老人查授权成员 |
| mg_medication | idx_generic / idx_brand | 药品搜索 |
| mg_conflict_rule | uk_code / idx_type | 规则同步 / 分类筛选 |
| mg_med_plan | idx_elder(elder_id,active) | 今日任务生成 |
| mg_checkin | uk_plan_time / idx_elder_day / idx_plan_status | 防重 / 按日拉取 / 漏服扫描 |
| mg_reminder | uk_dedupe / idx_elder_status | 去重 / 未读列表 |
| mg_qa_log | idx_user / idx_refused_time | 个人历史 / 拒答率统计 |
| mg_recognize_log | idx_user | 识别历史 |
| mg_audit_log | idx_time / idx_user_time | 时间线 / 按人追溯 |
| mg_family_alert | uk_dedup / idx_family / idx_elder_level | 推送去重 / 家属收件箱 / 老人风险聚合 |

> 设计说明：演示量级下全表扫描也无压力，补索引是为答辩时能讲清"**哪些高频查询走了什么索引、为什么这样设计**"，也是生产化的正确姿势。`ensureIndex` 通过 information_schema 判存，重复启动不会报错。
