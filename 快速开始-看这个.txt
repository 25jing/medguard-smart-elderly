        或项目根目录里的「启动平台-双击我.bat」。
   · 会附带弹出两个黑窗口：MedGuard-AI服务、MedGuard-后端，别关它们
   · 第一次启动 AI 服务要等约 30-60 秒（加载模型）
   · 看到自动弹出浏览器「统一入口」页 = 成功！

【手机上体验 H5 版】
   手机和这台电脑连同一个WiFi，手机浏览器访问：
       http://电脑IP:8080/
   电脑IP见启动窗口最后打印的「手机同一WiFi访问」那一行。
   打不开就是Windows防火墙拦了：首次启动时弹的防火墙提示要点"允许访问"，
   或临时关闭专用网络防火墙。
   震动提醒在 Android Chrome/微信里有效；iPhone Safari 不支持网页震动（会用弹窗+语音代替）。

【停止】双击「停止平台-双击我.bat」；或直接关掉 MedGuard-* 那几个黑窗口。

【常见问题】
 1) 双击后窗口一闪而过？
    → 不要"右键-以管理员身份"之外的奇怪姿势，正常双击即可。
      若仍闪退，按 Win+R 输入 cmd 回车，把
      D:\智慧养老安全用药辅助平台\启动平台-双击我.bat
      整个路径拖进窗口回车，就能看到报错文字，把文字发给老师/AI。
 2) 窗口显示「后端已在 8080 端口运行 / AI 服务已在 8100 端口运行」？
    → 说明服务早就活着，不是错误！直接访问
      http://127.0.0.1:8080/ 就行。
 3) 页面能打开但问答/识别报"AI服务不可用"？
    → 看 MedGuard-AI服务 窗口是否还在加载（首次约1分钟）；
      加载完成会打印 "Uvicorn running on 0.0.0.0:8100"。
 4) 统一入口页状态灯有红的？
    → 红灯=对应服务没起来。数据库红：双击「停止平台」再「启动平台」重来；
      AI红：等1分钟或看 MedGuard-AI服务 窗口的红字。
 5) 数据库连不上 / 后端启动报错？
    → 双击「停止平台-双击我.bat」再「启动平台-双击我.bat」重来一次；
      仍有问题把 MedGuard-后端 窗口的红字发回来。
 6) 想跑自动化验收？
    → 在项目根目录按住Shift右键空白处→"在此处打开PowerShell窗口"，执行：
      powershell -NoProfile -ExecutionPolicy Bypass -File scripts\e2e-test.ps1      （主回归36项）
      powershell -NoProfile -ExecutionPolicy Bypass -File scripts\e2e-family.ps1    （家属端14项）

【大模型问答（可选增强）】
   在 ai-service\.env 里填入你的百炼 API Key（参照 .env.example），
   重启 AI 服务后问药助手升级为 qwen-plus 受控生成（仍强制引用来源+拒答）。
   不配置也完全可用（本地知识库摘编模式，数据不出机器）。

  微信小程序怎么做（已验证：npm 命令行编译成功）
══════════════════════════════════════════════════
 【最快路径】编译产物已在包里，直接导入：
 1. 安装「微信开发者工具」稳定版
    https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
 2. 打开工具 → 导入项目 → 目录选：
    frontend\uniapp-miniprogram\dist\build\mp-weixin
    AppID 点「测试号」
 3. 详情 → 本地设置 → 勾选「不校验合法域名...」
 4. 模拟器即可登录使用（后端需先双击「启动平台-双击我.bat」跑起来）
    登录页有「老人演示 / 家属演示」两个芯片，点一下自动填账号。
 【改了源码后重新编译】：
    cd frontend\uniapp-miniprogram
    npm install
    npm run build:mp-weixin
