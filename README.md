# 💊 智慧养老安全用药辅助平台（MedGuard · 安心药助手）

> 北方民族大学 大学生创新创业训练计划项目 · 软件工程 2025 级 竟恒鑫
> 一套面向老年人的**拍照识药 → 循证问答 → 冲突校验 → 用药打卡 → 家庭协同**全链路安全用药辅助系统

## ✨ 核心功能

| 模块 | 能力 | 关键设计 |
|---|---|---|
| 📷 拍照识药 | 拍药盒 → OCR → Top-3 候选药名 | YOLOv8 检测 + RapidOCR(PP-OCRv4) + 68 药词典归一化（编辑距离），低置信度如实标记，原图即传即删 |
| 💬 问药助手 | 有依据才回答的用药问答 | LangChain RAG：bge-small-zh 向量 + BM25 混合召回(RRF) → 余弦重排 → 逐条来源标注；三重拒答（无依据/超范围/编造药名） |
| ⚖️ 冲突校验 | 四类用药风险自动预警 | 成分重复/同类叠加/禁忌配伍/老年慎用，39 条规则（Beers 2023 + 中国老年PIM标准2017），HIGH/MEDIUM/LOW 分级 + 大白话解释 + 文献依据 + 药师审核流 |
| ✅ 用药打卡 | 到点提醒、一键打卡 | 可解释判定：±10min按时 / 10-60min迟打 / >60min漏服（可补卡转LATE），依从率统计与趋势 |
| 👨‍👩‍👧 家庭协同 | 授权矩阵 + 脱敏汇总 | 老人授权三项独立开关（摘要/依从/提醒），家属只见脱敏汇总（张*芳、阿司**），随时可撤销 |
| 🛡️ 管理后台 | 数据看板 + 知识库/规则库维护 + 三类日志审计 | Vue3+Element Plus+ECharts；药品编辑版本+1并热同步AI；规则审核通过即热推送；越权403拦截 |
| 👴 适老化 | 大字号/大按钮/语音朗读 | 字体三档(20/22/24px)、56px+按钮、Web Speech 中文朗读、≤3步识药、高对比配色 |

## ⚠️ 诚实声明与已知局限

1. **医疗免责**：本平台是辅助工具，不能替代医嘱；种子知识数据整理自公开说明书要点与权威标准（Beers 2023 / 中国老年PIM标准 2017 / 各指南），**未经执业药师逐条复核**（数据带 `reviewedBy` 待复核标记，管理端内置审核流），不可直接用于生产。
2. **药盒检测**：默认演示模式（yolov8n COCO 通用检测 + 全图 OCR），响应中以 `detect.mode` 如实标注；挂自训权重（`MEDBOX_YOLO_MODEL`）即切换真实检测裁剪。OCR 对艺术字/反光/褶皱药盒识别率下降，提供手动输入兜底。
3. **问答**：默认抽取式合成（逐句来自知识库并标注来源，宁拒答不编造）；配置 LLM Key 后升级为受控生成（仍强制引用与拒答）。
4. **小程序端**为可编译源码工程，需 HBuilderX/微信开发者工具环境；本仓库交付源码与说明。
5. 演示密钥（JWT/服务间）为明文默认值，生产必须更换；未含 HTTPS/容器化（部署手册给出路线）。
